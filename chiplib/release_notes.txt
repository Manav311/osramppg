AS7058 Chip Library - Release Notes
===================================

Release Info
------------
- Software Package Name:    AS7058 Chip Library
- Date of Release:          2024-06-13
- Version Number:           4.2.1
- Supported Arch and OS:    x86-64_win10, x86-64_linux, arm-cm4f_none_eabi

Linked Components
-----------------
- css-sw-utilities (v4.6.0):   Contains error code definitions, standard include
                               header.
- vital-signs-agc (v2.1.0):    Contains AGC algorithm.

Highlights
----------
This library enables the user to configure the registers of AS7058 and get
cyclic measurement data. An OSAL based on AS7058 EVK supports ChipLib on host
PCs.

Documentation
-------------
See as7058_chiplib_doc_v4.2.1.pdf

Instructions for usage
----------------------
- Compiler flag 'AS7058_FIFO_DATA_BUFFER_SIZE' can be used to overwrite the
  internal buffer size for FIFO data. Default is 1536 bytes.

Further dependencies
--------------------
- Needs to be connected with ams OSRAM AS7058
