Version 3.0.0
*******************************************************************************

Version comment

        New BioZ measurement mode to support advanced post-processing.

Added

        n/a

Changed

        - Implements a more complex measurement sequence in the BioZ measurement
          mode to perform in-phase and quadrature measurements for short
          circuit, reference resistor, body impedance, wrist impedance, finger
          impedance, and total impedance.
        - Moves EDA scaling special measurement mode to a separate module.
          Increases the number of temperature samples that are acquired for
          averaging. Now sets result field temperature_adc to UINT32_MAX when
          temperature measurements are disabled.

Deprecated

        n/a

Removed

        n/a

Fixed

        - Stops the measurement twice to solve an issue inside the chip
          where a new measurement can't be started correctly again.

Known issues & limitations

        - Measurement config function returns wrong sample period if ECG SEQ1 is
          used with an averaged signal and a non-averaged signal.
